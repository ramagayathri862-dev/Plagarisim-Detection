Plagiarism Detection Using DSA

A Java-based Plagiarism Detection System that compares text documents using different Data Structures and Algorithms.

🚀 Algorithms Used
Naive String Matching
KMP (Knuth-Morris-Pratt)
Rabin-Karp
LCS (Longest Common Subsequence)
Cosine Similarity
Suffix Array
Kasai Algorithm
🎯 Features
Detects similar text between documents
Performs pattern matching
Calculates document similarity
Demonstrates multiple DSA techniques
Compares different algorithm approaches
🛠️ Technologies
Java
Data Structures & Algorithms
String Matching
Dynamic Programming
Hashing
